# Nonfiction Academy real

사내 기업용 LMS 플랫폼을 만들거야! 첨부한 마크다운을 참고하여 만들되, 디자인 컨셉은 Toss UI/UX처럼 직관적이고 단순화하되, 절대 이모지를 쓰지말고 아이콘을 적용해! 그리고 해당 시스템의 사용자는 뷰티회사인 nonfiction.com(논픽션)이야! 디자인에 매우 민감한 회사고 이 회사의 디자인 경향을 차용해서 UI/UX 를 적용해! 사용자에 대한 다국어 페이지(영어/일본어/중국어)도 작업을 해야하는데, 이것은 한글 페이지가 끝나면 추가 작업을 할거야! 사내교육용이므로 폐쇄형으로 로그인 페이지를 설계를 해주면 돼! 첨부한 이미지를 참고해!
