# 교육·코칭 시간 보고서 내려받기 완료 결과

2026년 11월 16일 기준으로 이번 구현과 검수를 완료합니다. 전체 기능은 기존 평가인 **65% 완료·35% 남음**을 유지합니다. 내려받기 하위 기능 추가만으로 기능 전체를 완료로 바꾸지 않습니다.

이번 주소는 기존 회의 시연 주소와 다릅니다. 로그인이 필요하며 기존 회의 시연용 비밀번호를 이번 초안에서 그대로 쓰지 않습니다. 검수에는 이번 초안 안에서 새로 준비한 비밀번호로 직접 로그인합니다. 비밀번호와 로그인 인증 자료는 이 문서나 구현 코드에 기록하지 않습니다. 외부 주소에서 사용자가 직접 로그인하는 과정은 별도로 확인해야 합니다.

보고서에서 기간과 보고 단위를 선택한 뒤 오른쪽 아래 방향 화살표를 누르면 엑셀에서 열 수 있는 한국어 파일을 내려받습니다. 컴퓨터에서는 아이콘에 마우스를 올리면 ‘보고서 내려받기’가 표시됩니다.

## 성공한 확인

- 직원·지정 선임매니저·본사 교육팀이 실제 로그인 화면에서 로그인합니다.
- 세 역할에서 개인·매장·지역·글로벌의 네 단위로 파일 총 12개를 내려받고, 한국어 표시·기간·단위·행 수·시간 값·비공개 표시가 화면과 일치함을 확인합니다.
- 직원 예시 값은 온라인 52분·교육 115분·현장 코칭 25분·매니저 코칭 30분입니다. 본사는 매니저 코칭 0분과 일부 비공개 표시를 유지합니다.
- 휴대전화 크기로 새로 연 화면에서도 세 역할의 파일을 내려받습니다. 컴퓨터와 휴대전화 크기에서 보고서의 페이지 넘침이나 실행 오류는 발견하지 않습니다. 표는 가로로 이동하며 확인합니다.
- 내려받기는 기존 조회를 새로 실행합니다. 화면과 파일 사이에 값이 달라지면 새로 허용된 값으로 파일과 화면을 맞춥니다.

## 차단한 확인

- 직원의 현재 소속이 등록된 소속과 달라진 상태에서는 예전 화면에서 눌러도 파일을 만들지 않습니다.
- 선임매니저 지정이 해제되면 다른 직원 기록을 제외하고 본인 결과만 내려받습니다. 일반 직원으로 본인 보고서를 보는 기존 권한은 유지합니다.
- 검수 명단에서 해제된 본사 계정은 예전 화면에서 눌러도 파일을 만들지 않습니다.
- 자동 검사로 오류·빈 결과·조회 중·중복 클릭·조회 도중 기간 변경을 확인합니다. 새 조회가 거부되면 이전 파일을 대신 만들지 않습니다.
- 한국어 문자 표식과 쉼표·따옴표·줄바꿈 보존, 수식 실행 위험 문자 보호를 확인합니다.

## 검사 근거

관련 자동 검사 52개와 기존 회의 권한 검사 6개를 통과합니다. 최신 화면 준비 결과는 정상이며 종료 시 운영 분리 점검 20항목을 통과합니다. 기존 예시 자료만 사용하며 이번에 새 예시 행은 추가하지 않습니다. 권한 변경 시험 후 이번 초안의 소속·지정·검수 자격을 복구합니다.

## 미검수와 대기

실제 고객 컴퓨터·휴대전화·설치앱, 엑셀 프로그램 자체에서 파일을 여는 과정과 위 외부 주소에서의 직접 로그인은 미검수입니다. 내부 브라우저 검수 결과와 구분합니다. 휴대전화 크기는 내부 검수 브라우저에서 확인한 결과이며 실제 휴대전화 확인을 뜻하지 않습니다.
