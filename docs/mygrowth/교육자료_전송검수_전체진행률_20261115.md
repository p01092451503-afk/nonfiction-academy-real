# 교육자료 대용량·문서별 전송 검수와 전체 진행률

작성일: 2026년 11월 15일입니다.
대상은 「마이그로스 교육자료 50MB·문서별 전송 검수」 초안입니다.

## 이번 결론

합성 문서 7종과 유효한 50MB 파일의 저장·재조회·다운로드 원본 일치를 확인했습니다. 이번 검수에서 실제 자료 기능의 결함은 발견하지 않아 화면·전송·권한 구현을 변경하지 않았습니다. 추가 회귀 검사만 보강합니다. 초안은 수락하거나 게시하지 않습니다.

## 이번에 실제 확인한 내용

- 이번 초안의 분리 적용 및 최초·종료 확인 20항목이 통과합니다. 이전 초안의 결과를 이번 근거로 사용하지 않습니다.
- 워드 기존·최신, PDF, 엑셀 기존·최신, PPT 기존·최신 7종을 실제 문서 생성 도구로 준비합니다. 고객 문서가 아닌 합성 자료입니다.
- 담당자 교육 상세에서 자료를 등록하고 화면을 다시 열어 저장된 목록을 확인합니다. 참석 직원 교육 상세에서 내려받고 새로고침 후 같은 본인 링크를 다시 이용합니다.
- 문서 7종과 정확히 52,428,800바이트인 PDF의 다운로드가 각각 등록 원본과 해시가 같습니다. 경계 PDF는 정상 페이지·내장 파일을 가진 문서로 별도 문서 판독기로 확인합니다.
- 52,428,801바이트 파일은 화면과 실제 전송에서 거부합니다. 워드 내용을 PDF로, 엑셀 최신 내용을 워드 최신으로, 엑셀 기존 내용을 워드 기존으로 위장한 3종도 거부합니다.
- 아직 유효한 링크도 참석 취소, 직원 소속 변경, 담당자 소속 변경·지정 해제 후 실제 파일 요청과 화면에서 차단합니다. 만료된 링크도 차단합니다.
- 다른 지점, 다른 매니저, 미허용 직원은 자료 목록·파일 요청이 거부됩니다. 교육 열람 권한이 있는 담당자도 다른 직원에게 발급한 티켓은 사용할 수 없습니다. 본인은 현재 권한과 유효기간 안에서 재사용할 수 있습니다.
- 비공개 파일 직접 접근과 공개 경로 접근을 거부합니다. 새 공개 주소·새 권한을 추가하지 않습니다. 이미 기기에 내려받은 사본은 회수 대상이 아닙니다.
- 직원·담당자 예시 소속은 검수 뒤 원래 상태로 복구합니다. 소속 변경은 담당 지정도 해제하므로 예시 담당 지정도 복구합니다. 기존 온라인 진도·수료·세션 원본은 검수 전후 값이 같습니다.
- 컴퓨터 1280×1800, 휴대전화 390×844의 자료·다운로드 화면을 확인합니다. 가로 넘침은 없으며 실제 로그인 흐름의 화면 실행 오류는 0건입니다.

## 검수 방법의 한계

이번 브라우저 검수 도구는 선택한 파일의 내용을 중계할 때 누락하는 문제가 있습니다. 이를 실제 기능 오류와 구분하기 위해 검수 도구에서 선택된 동일 파일과 교육 식별자를 그대로 초안의 실제 비공개 전송 기능에 보냅니다. 성공 응답을 꾸미거나 파일·권한 검사를 생략하지 않습니다. 별도 직접 전송에서도 문서 7종·50MB 성공과 초과·내용 불일치 거부를 확인합니다. 따라서 **일반 브라우저가 보내는 원래 파일 요청 전체 경로는 미검수**이며, 선택·등록·재조회·다운로드 화면과 실제 자료 서비스 전송은 확인한 범위로 구분합니다. 앱 연결 주소를 변경하지 않습니다.

실제 고객 문서 표본, 고객 휴대전화, 실제 설치앱, 모든 언어·기기 조합은 미검수입니다. 영구 보관은 자동 만료·삭제가 없는 현재 구조를 확인한 것이며 수년 보관이나 무제한 저장·백업 보장 검수가 아닙니다. 이번에 초안에 추가한 합성 파일은 운영 자료가 아닙니다.

완료 7개, 부분 구현 10개, 미구현·대기 3개를 유지합니다.

완료는 1점, 부분은 0.5점, 대기는 0점이며 모든 기능의 비중은 같습니다.

(7×1 + 10×0.5 + 3×0) ÷ 20 × 100 = **완료 참고치 60%, 남은 비율 40%**입니다. 남은 시간·비용·운영 공개율이 아닙니다.

## 남은 항목과 필요한 외부 결정

- 자료 검수: 실제 설치앱·고객 기기·고객 문서 표본 및 검수 도구 중계 보정 없는 브라우저 원래 업로드 경로를 확인합니다.
- 보고와 팀 현황: 고객의 산식·기간·분모·공개 권한 결정이 필요합니다.
- 후속 판정: 개선 판정 의미·예정일·판정 후 실행 계획 수정 정책 결정이 필요합니다.
- 번역·추가 피드백: 민감 원문 전송·보관·공개 승인과 용도 결정이 필요합니다.
- 외부 성과·과거 자료: 시험 연결 명세·표본·대응 기준이 필요합니다.
- 최종 통합·베타·공개: 별도 고객 화면·대상·공개 승인이 필요합니다. 이번 초안은 수락·게시하지 않습니다.
