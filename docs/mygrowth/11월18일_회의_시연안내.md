## 4. 회의에서 눌러 볼 순서

### 직원 계정
1. 기존 학습 대시보드에서 학습 현황·진행 중 강의와 올해 성장 이력을 함께 확인합니다.
2. 11월을 눌러 월별 성장 여정을 봅니다.
3. 내 강의에서 온라인 강의와 오프라인 교육이 함께 보이는 것을 확인합니다.
4. 「신제품 향과 고객 응대 교육」 상세에서 교육자료(PDF)를 내려받습니다.
5. 필드 코칭 「향 취향 상담과 시향 안내」 상세에서 관찰·피드백·실행 계획·후속 판정 이력을 봅니다.
6. 실행 계획 화면에서 본인 계획을 확인합니다.

### 담당 선임매니저 계정
1. 기존 왼쪽 메뉴의 담당 직원·팀 성장 현황·오프라인 교육·코칭 등록을 확인합니다.
2. 팀 성장 현황에서 성수 지점 직원의 학습·참석·코칭·계획 요약을 봅니다.
3. 직원 이름을 눌러 직원 성장 여정과 상세로 이동합니다.
4. 담당 직원 계획·후속 판정에서 판정 이력(진행 중 → 이행 완료)을 봅니다.
5. 보고서에서 본인 지점의 교육·코칭 시간을 봅니다.

### 본사 교육팀 계정
1. 기존 관리자와 같은 메뉴 구성의 회원·조직 영역에서 직원 관리·성장 현황을 열고 지점을 골라 봅니다.
2. 보고서에서 보고 단위(개인·매장·지역·글로벌)와 기간을 바꿔 봅니다.
3. 매니저 코칭 시간이 '일부 비공개'(0분)로 나오는 것을 확인합니다.

## 5. 들어 있는 예시 자료

- 온라인 강의 2개: 수료 1건, 진행 중 1건(35%), 학습 세션 3건
- 오프라인 교육: 참석 확인된 교육 2건, 참석 확인 전 교육 1건
- 필드 코칭 1건, 매니저 코칭 1건(모두 참석 확인)
- 실행 계획 2건, 후속 판정 이력 2건(진행 중 → 이행 완료 정정)
- 교육자료 1건: 「향_서비스_교육자료_시연.pdf」(약 3KB)

1. **매니저 코칭 공개 범위**: 지금은 직원 본인과 작성한 스토어매니저만 봅니다. 본사 교육팀과 트레이너에게 시간 합계나 내용을 보여줄지 정해야 합니다.
2. **본사 교육팀의 직원 상세 공개 여부**: 지금 본사 교육팀은 팀 요약만 보고 직원 상세로 들어갈 수 없습니다.
3. **후속 판정 기준**: 기획서의 '개선됨·추가 개선 필요'와 지금의 '이행 완료·진행 중·미이행' 중 무엇을 쓸지, 후속 확인 예정일을 둘지 정해야 합니다.
4. **보고서 세부 산식**: 지역을 국가로 묶는 기준, 실제 시간이 없을 때 계획 시간으로 셀지, 온라인 시간 반올림 방식, 날짜 기준(한국시간)을 확인해야 합니다.

## 7. 알려 드릴 점

- 이번 통합은 기존 학습 홈·내 강의와 공통 메뉴·상단 영역을 실제로 재사용합니다. 온라인 강의·코칭 상세로 이동해도 같은 메뉴를 유지합니다.
- 본사 교육팀에는 인사이트·회원·조직·학습 운영으로 업무를 배치합니다. 기존 관리자 권한을 추가하지 않습니다.
- 본사 직원 상세·지점 상세 안의 최종 탭 통합과 기존 알림·다국어 관리 통합은 아직 완료되지 않았습니다. 기존 관리자 페이지의 수정 기능을 교육팀에 그대로 열지 않습니다.

- 교육자료 파일은 이 시연 초안에만 들어 있습니다. 새 초안을 만들면 다시 등록해야 합니다. 나머지 예시 자료는 새 초안에도 자동으로 들어갑니다.
- 보고서 파일 내려받기는 아직 준비 중입니다.
- 실제 휴대전화 기기와 설치 앱에서는 확인하지 않았습니다. 휴대전화 크기 화면으로만 확인했습니다.
- 이 초안은 수락하거나 게시하지 않습니다.
