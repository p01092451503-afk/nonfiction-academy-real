# 마이그로스 중간 회의 화면·기능 동시 개발 계획

## 목표와 보호 조건

2026년 11월 18일 회의에서 **사용자 화면과 담당자 업무 화면을 직접 보며**, 실제 저장·재조회 흐름과 남은 작업을 확인하도록 준비합니다. 기능을 모두 만든 뒤 디자인하지 않고, 이미 만든 기능부터 고객 시안의 정보 순서와 이동 흐름에 연결합니다.

이 초안에서만 작업합니다. 기존 로그인, 학습자·관리자·최고관리자·러닝매니저 화면과 메뉴, 운영 기록·권한·백업은 변경하지 않으며 **수락하거나 게시하지 않습니다**. 작업 재개와 검수 전에 운영 차단을 다시 확인하고 실패가 하나라도 있으면 중단합니다.

## 확인한 현재 상태

- 운영 차단 적용과 재검증 20개를 통과했습니다. 외부 메일·인증·서버 요청·파일 연결을 차단하고 예약작업이 없음을 확인했습니다.
- 첨부 시안 5장과 고객 공유 문서, 요구사항 분석, 개발 프롬프트, 20개 기능정의서를 확인했습니다. 과거 문서의 운영 메뉴 추가·기존 권한 확대 지시는 적용하지 않습니다.
- 담당자 지정, 교육·두 코칭 등록, 참석 확인, 본인 학습 목록, 실행 계획, 후속 판정·정정 코드가 있습니다. 순차개발 10번 후속 확인은 기능정의서 09번에 해당하며, 관련 구조 변경 기록도 있습니다. 이번 초안의 업무 재검수는 아직 하지 않았습니다.
- 연간 성장 표시·월별 이력, 사용자 코칭 상세에서 계획과 판정 연결, 사용자/담당자 메뉴 구분은 부족합니다. 교육자료 다운로드와 보고 화면은 완성되지 않았습니다.

## 회의 우선순위

| 순서 | 함께 완성할 화면과 동작 | 기능정의서 |
|---|---|---|
| 1 | 사용자/담당자 메뉴 분리, 사용자 본인 상세 조회 기반과 기존 저장 연결을 준비합니다. | 02·03·13·14 |
| 2 | 성장 홈의 프로필·인사, 1~12월 활동·유형 범례, 네 요약과 클릭 이동, 월별 날짜순 이력을 구현합니다. | 10·11 |
| 3 | 학습의 전체/오프라인/이러닝 탭, 연도, 전체/완료/진행 중 요약과 상세를 구현합니다. | 05·12 |
| 4 | 필드·매니저 코칭의 연도/상태 목록과 상세에 관찰·피드백·본인 실행 계획 편집·후속 이력을 연결합니다. | 06~09·13 |
| 5 | 담당자 지정·교육/코칭 등록·참석·직원 계획·판정/정정 업무를 정리하고 같은 기록을 직원 화면에서 다시 확인합니다. | 02·04~09·14·15 |
| 6 | 실제 계정으로 전체 흐름, 권한 차단, 기존 업무 유지, 컴퓨터·휴대전화 화면을 검수합니다. | 01·20의 검수 범위 |

사용자는 성장 홈·학습·필드 코칭·매니저 코칭의 핵심 네 화면을 중심으로 이동합니다. 휴대전화에는 하단 메뉴를, 컴퓨터에는 폭을 활용한 메뉴와 본문을 제공합니다. 미정인 추가 피드백 메뉴는 넣지 않습니다. 시안 559번은 소개·로그인 참고 자료로만 사용하며 운영 로그인은 교체하지 않습니다.

## 화면과 확인 주소

| 구분 | 준비할 주소 | 회의에서 확인할 내용 |
|---|---|---|
| 사용자 성장 홈 | `/my-growth` | 인사·프로필, 선택 연도 12개월 활동, 유형 범례, 네 요약의 목록 연결을 확인합니다. |
| 월별 이력 | `/my-growth/timeline/:yyyymm` | 월 이동, 날짜순 기록, 올바른 상세 이동과 뒤로가기를 확인합니다. |
| 나의 학습 | `/my-growth/learning` | 교육 유형·연도·상태와 요약, 교육 상세를 확인합니다. |
| 나의 필드·매니저 코칭 | `/my-growth/coaching`, `/my-growth/manager-coaching` | 본인 코칭 목록과 상세, 실행 계획 저장·수정 및 판정 이력을 확인합니다. |
| 담당자 업무 | `/my-growth/workspace` 아래 지정·교육·코칭·계획 화면 | 서버가 허용한 업무만 표시하고 등록·참석·판정·정정을 확인합니다. |

현재 `/my-growth/training`, `/my-growth/assignments`, `/my-growth/plans`의 저장 기능은 재사용합니다. 주소를 정리할 때 기존 검수 주소는 안전한 연결을 남기되, 직원용 코칭 목록과 담당자 등록 화면은 분리합니다. 최종 주소와 진입 방법은 실제 검수 후 안내합니다.

## 보여줄 내용과 남겨둘 내용

고객 시안의 정보 순서·연간 표시·날짜별 목록·상태·상세에서의 행동을 구현합니다. 글꼴과 색은 현재 프로젝트 기준을 유지하며 유형과 상태를 의미형 색상으로 구분합니다. 영어 예시·인명·숫자는 실제 조회 결과와 번역 문구로 대체합니다. 프로필 사진이 없으면 이름 기반 표시를 사용합니다.

교육자료가 없거나 자료 기능이 미완성이면 이를 구분하고 가짜 다운로드를 넣지 않습니다. 보고서, 외부 성과 연결, 과거 자료 이관, 민감 기록 외부 번역은 이번 핵심 화면 완료로 가장하지 않습니다. 후속 기능은 20개 기능 범위 안에서 이어갑니다.

스탬프를 성과 점수로 해석하지 않습니다. 우선 활동 유무·건수를 표시하고 크기/점수 규칙은 확정 전 적용하지 않습니다. 후속 판정은 기존 이행 완료·진행 중·미이행 값을 유지하고 자동 14일 마감·반복 규칙, 완료 후 수정 잠금 등 미확정 조건을 임의로 추가하지 않습니다. 현재 수정 허용 상태를 회의 결정 항목으로 명시합니다. 상태 요약은 최신 판정과 판정 당시 계획을 함께 확인하며 계획 수정으로 오래된 완료 판정을 현재 완료처럼 표시하지 않습니다.

## 기술 적용 범위

- 접근은 기존 검수 명단 확인을 유지합니다. 본사 한국 교육팀의 지정 권한, 지점 선임매니저의 담당 역할과 현재 소속 지점은 서버 확인으로만 판단하고 실패 시 닫습니다. 기존 이러닝 관리자 역할을 새 권한으로 사용하지 않습니다.
- 연간·월별·학습·코칭 화면은 동일 원본 식별자와 본인 조회를 재사용합니다. 직원 상세에 부족한 담당자·관찰·피드백·계획·최신 판정 항목만 별도 보호된 조회로 보완합니다. 담당자 조회는 기존 종류별 담당 범위를 유지합니다.
- 필요한 새 자료 구조와 서버 조회 변경은 이 초안에만 기록합니다. 기존 회원·진도·수료·역할 구조를 바꾸지 않습니다. 이미 기록된 후속 판정 변경을 다시 만들지 않습니다.
- 계획·판정 저장 후 해당 사용자의 성장·목록·상세 조회를 갱신하며, 계정 전환과 권한 회수 시 이전 민감 내용이 남지 않도록 합니다.
- 화면 문구는 한국어·영어·일본어·중국어·광동어를 함께 준비하고 작성 원문은 보존합니다. 외부 번역 요청은 보내지 않습니다.
- 예시 자료가 필요한 경우 이 초안에만 추가합니다. 실제 운영 인물·학습 기록을 복사하지 않고 중복 적용에도 같은 예시가 유지되도록 준비합니다.

## 검수와 완료 기준

1. 기존 구현의 규칙별 검사를 먼저 실행하고 필요한 새 규칙 검사를 추가합니다. 이번 초안에서 통과한 결과만 완료로 표시합니다.
2. 직원 로그인 → 기록 조회 → 상세 → 계획 저장 → 새로고침 → 같은 계획 재조회 → 담당자 로그인 → 판정·정정 → 직원 로그인 → 이력 확인을 실제 권한으로 실행합니다.
3. 홈·월별 이력·학습·코칭 요약과 상세의 동일 기록/조건을 대조합니다. 참석 취소·계획 변경·판정 정정도 반영되는지 확인합니다.
4. 다른 직원·지점·회사, 미지정 관리자/최고관리자/러닝매니저의 화면과 직접 조회·저장 요청을 차단하고 권한 회수 후에도 확인합니다.
5. 컴퓨터와 휴대전화에서 네 사용자 화면 및 담당자 입력·상세를 확인합니다. 하단 메뉴 가림, 글자 넘침, 빈 기록·오류·재시도 상태를 확인합니다.
6. 기존 네 역할의 로그인·학습·메뉴와 진도·수료 유지 검사를 실행합니다. 외부 영상 등 차단 때문에 확인하지 못한 항목은 따로 보고합니다.
7. 운영 차단을 다시 검증하고 화면 주소·확인 방법·완료·미완성·고객 결정 대기를 한국어로 전달합니다. 초안 수락·게시 없이 이 초안에서 다음 기능을 이어갑니다.
