# 5번 참석 관리

기존 오프라인 교육의 상세 화면에 참석 관리를 추가합니다. 이 초안에서만 개발하며 운영 사이트와 실제 학습 기록은 변경하지 않습니다.

- 등록된 참석 대상에서 실제 참석 직원을 선택하고 **참석 저장**을 누릅니다.
- 저장 전에는 **참석 확인 대기**, 저장 후에는 선택한 직원은 **참석자**, 나머지는 **미참석자**로 나누어 표시합니다. 전원 미참석도 저장할 수 있습니다.
- 기존 본사 한국 교육팀과 해당 지점의 지정 트레이너만 저장·수정합니다. 다른 지점 및 미지정 계정은 차단합니다.
- 저장된 참석 내역을 다시 수정할 수 있으며 변경 이력을 남깁니다. 다른 담당자가 먼저 수정한 경우 덮어쓰지 않고 새 내역을 확인하도록 합니다.
- 교육자료 업로드·학습시간 누적·수료 처리는 이번 요청에 포함하지 않습니다.

## 기술 및 검수

참석 상태를 기존 교육 대상과 연결해 별도 항목으로 보관하고, 서버에서 권한을 재확인한 뒤 한 번에 저장합니다. 기존 학습 기록은 읽거나 쓰지 않습니다. 참석 저장·분리 조회·수정·전원 미참석·권한 회수·타 지점 차단·부분 실패 취소·동시 수정 충돌을 검사하고 컴퓨터와 휴대전화에서 저장 후 새로고침하여 확인합니다.

확인 경로는 이 초안에서 지정 검수 계정으로 로그인한 뒤 **/my-growth/training → 상세 보기**입니다.
