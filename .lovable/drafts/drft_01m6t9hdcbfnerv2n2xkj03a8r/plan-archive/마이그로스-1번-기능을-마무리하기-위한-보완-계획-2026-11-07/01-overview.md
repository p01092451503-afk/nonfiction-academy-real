# 마이그로스 1번 기능을 마무리하기 위한 보완 계획

## 이번 검증 결과

차단 적용과 재검증 20개 항목을 모두 통과했습니다. 초안의 예약작업은 0건이며, 외부 요청 5곳이 실제 차단되고 시험 메일은 내부 수신함에만 도착합니다.

네 역할의 예시 계정을 추가하고 로그인 및 기존 역할 화면 진입을 확인했습니다. 가상 이미지 차시의 완료 기록도 저장하고 다시 조회했습니다. 진도는 100%, 완료 횟수는 1입니다.

다만 **새 화면의 주소는 막히지만 미지정 관리자와 최고관리자는 새 활동 자료 14건을 직접 조회할 수 있습니다.** 따라서 전체 격리와 1번 기능은 아직 완료가 아닙니다. 관리자 로그인 직후 학습자 화면으로 먼저 이동하는 현상도 추가 검수가 필요합니다.

## 보완할 내용

1. 새 활동 자료 조회에 서버 검수 명단 확인을 반드시 적용합니다. 관리자·최고관리자라는 이유만으로 허용하지 않습니다.
2. 지정 검수자는 본인 예시 자료만 조회하도록 유지합니다. 검수 명단은 일반 계정이 조회하거나 수정하지 못하도록 확인합니다.
3. 같은 다섯 계정으로 주소 진입과 직접 자료 요청을 다시 검사합니다. 서버 오류·빈 응답·명단 회수도 차단되는지 확인합니다.
4. 예시 자료를 반복 적용해도 중복 활동이 생기지 않도록 정리합니다.
5. 기존 로그인 직후 이동, 학습 완료 재조회, 휴대전화 화면, 메뉴 이동 시 좌측 메뉴 유지까지 회귀 검수를 마칩니다.
6. 모든 검수를 통과한 경우에만 1번 기능을 완료로 기록하고 2번 역할·담당 조직 기능 준비로 넘어갑니다.

## 운영 보호

이번 보완은 이 초안에서만 진행합니다. 운영 사이트·실제 학습 기록·기존 역할을 변경하지 않으며 초안을 수락하거나 게시하지 않습니다. 자료 구조 보완은 지금 이 초안에만 적용되며, 추후 초안을 수락하면 앱에 전달되므로 이번 작업에서는 수락하지 않습니다. 초안의 예시 자료는 앱으로 이동하지 않습니다.

## 기술 확인 사항

- 이미 기록된 기존 마이그레이션은 수정하지 않고 추가 마이그레이션으로 활동 조회 정책을 보완합니다.
- `is_mygrowth_reviewer()`를 자료 정책과 주소 경계의 공통 검수 조건으로 사용합니다.
- 기존 역할 우선순위는 바꾸지 않고 로그인 직후 이동 현상을 재현·진단합니다.
- 실제 자료 요청의 미지정 관리자 조회 결과가 14건에서 0건으로 바뀌는지 같은 검사로 확인합니다.
- 오류·명단 회수는 실제 요청과 경계 테스트로 검증합니다.
