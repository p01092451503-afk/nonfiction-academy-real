## 권한과 자료 보호
- 모든 조회·등록에서 서버가 검수자 여부를 다시 확인하며 오류가 나면 차단합니다.
- 지정된 트레이너는 현재 소속 담당 지점만 등록·조회합니다. 기존 관리자·최고관리자·러닝매니저 권한만으로는 접근할 수 없습니다.
- 별도 승인된 본사 한국 교육팀은 승인된 회사 안에서만 관리합니다. 담당자는 선택 지점에 유효하게 지정된 트레이너만 선택합니다.
- 직원의 현재 소속과 재직 상태를 저장 시 다시 검사합니다. 다른 회사·지점 직원이나 권한이 회수된 담당자를 넣은 요청은 거부합니다.
- 직원에게는 아직 참석이 확인되지 않은 교육을 완료 기록으로 공개하지 않습니다.

## 기술 구현
- 교육 원본과 참석 대상 연결을 새 자료 구조로 분리하고, 직접 쓰기는 막으며 서버 함수에서 한 거래로 저장합니다.
- 등록 요청 식별자와 입력 내용을 보관합니다. 같은 요청은 같은 교육을 반환하고, 같은 식별자로 다른 내용을 보내면 거부합니다.
- 회사·지점은 신뢰된 교육팀·직원 명단과 현재 소속을 대조합니다. 기능 02의 지정 검증과 기능 01의 서버 접근 확인을 재사용합니다.
- 기존 성장 기록에 이수 결과를 연결하는 처리는 참석 기준이 정해지는 기능 05에서 추가합니다. 기존 이러닝 자료에는 쓰지 않습니다.
- 이번 자료 구조 변경은 현재 초안에만 적용합니다. 초안을 수락하면 구조 변경도 앱에 반영되므로 이번에는 수락하지 않습니다. 초안의 예시 자료는 앱으로 옮겨지지 않습니다.

## 완료 검수
1. 예시 직원 여러 명을 선택해 교육을 등록하고 새로고침 후 상세와 명단이 동일한지 확인합니다.
2. 같은 요청의 재전송으로 교육이 하나만 생성되는지 확인합니다.
3. 잘못된 참석자를 포함하면 교육과 참석 대상 모두 저장되지 않는지 확인합니다.
4. 다른 지점·회사, 미지정 네 역할, 담당자 해제·검수 명단 회수 후 조회와 저장이 차단되는지 확인합니다.
5. 실제 시간 미입력 상태를 보존하고 기존 진도·수료 값이 그대로인지 확인합니다.
6. 기존 로그인·학습 화면과 관리자 메뉴 유지 여부를 검사하고 컴퓨터·휴대전화에서 입력과 상세 표시를 확인합니다.

교육 유형 목록, 실제 시간 입력 책임, 참석 확정·수정·취소 담당자, 교육자료 허용 기준은 11월 18일 고객 확인사항으로 남깁니다.
