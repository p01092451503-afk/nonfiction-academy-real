# 6번 나의 학습 목록

직원이 자신의 교육·코칭·성장 기록을 한눈에 확인하는 **나의 학습 목록**을 추가합니다. 기존 학습자 화면과 메뉴는 수정하지 않고, 지정 검수자만 접근하는 마이그로스 화면 안에 배치합니다.

- 상단에서 교육·코칭·성장 활동 건수를 확인합니다.
- 최근 기록부터 표시하며 제목 검색과 유형·상태·기간 선택을 제공합니다.
- 교육에는 기존 이러닝 참고 이력과 **본인 참석이 확인된 대면 교육**을 표시합니다. 참석 대기·미참석 교육은 이수 목록에 넣지 않습니다.
- 코칭 기록과 실행 계획·후속 확인 등 성장 활동을 함께 표시하고, 항목을 누르면 일자·상태·내용·계획 시간·실제 시간·진도 등 해당 기록의 상세를 확인합니다.
- 빈 목록·검색 결과 없음·불러오기·실패 후 재시도 화면을 구분합니다.

## 기술 및 검수

서버에서 지정 검수자 여부와 본인 소유 여부를 확인해 기존 자료를 읽기만 합니다. 동일 원본으로 연결된 기록은 중복 표시하지 않습니다. 참석 수정 시 목록도 최신 결과를 반영하며 기존 이러닝 수료·진도·시간이나 성장 완료 기록은 변경하지 않습니다.

본인 기록만 조회·타 직원 비노출·미참석 제외·명단 회수 차단·읽기 전용 불변을 검사합니다. 실제 로그인 후 목록→검색→필터→상세→새로고침을 컴퓨터와 휴대전화에서 확인하고 기존 역할 화면과 학습·메뉴 유지도 다시 검수합니다.

확인 경로: **이 초안 → 지정 검수 계정 로그인 → /my-growth/learning**입니다. 운영 반영·초안 수락·공개는 하지 않습니다.
