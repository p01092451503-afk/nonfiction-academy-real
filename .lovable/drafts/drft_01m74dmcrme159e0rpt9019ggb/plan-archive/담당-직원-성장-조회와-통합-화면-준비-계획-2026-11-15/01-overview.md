# 담당 직원 성장 조회와 통합 화면 준비 계획

2026년 11월 18일 중간회의에서 **직원 화면과 담당자 화면을 함께 보여주는 것**을 목표로 합니다. 이번에는 **담당 직원 선택 → 월별 성장 여정 → 허용된 학습·코칭 상세**까지 우선 연결합니다.

## 이번에 확인한 상태

- 이번 초안에서 분리 차단 적용 후 20개 점검을 통과했습니다. 실행 서비스 설정을 사용한 외부 요청 15건과 실제 서버 함수 내부 외부 요청 5건이 차단됐습니다. 직접 소켓 통신 호출은 발견하지 않았습니다.
- 원본 기획서와 확장통합 기획서, 현재 화면·조회 규칙, 11월 8일 검수 기록을 대조했습니다. 직원 본인의 성장 홈·학습·코칭 상세와 담당자의 계획 확인·판정은 존재하지만, 직원 선택 후 성장 여정을 보는 기능은 아직 없습니다.
- 기획서에는 팀원의 학습·현장·매니저 코칭 조회가 있으나 넓은 팀 열람과 담당자 간 민감한 피드백 공유는 미확정입니다. 이번에는 현재 허용된 범위만 제공합니다.
- 색상 관련 기억 파일은 현재 없으므로 기존 화면의 색상 정의와 디자인 요소를 기준으로 준비합니다. 전체 사이트 디자인은 바꾸지 않습니다.

## 이번 개발 범위

1. **직원 관리:** 현재 지점의 지정 담당자가 기존에 열람 가능한 교육·코칭 대상 직원만 선택합니다. 직원 이름 검색과 지점 표시를 제공합니다.
2. **직원 성장 여정:** 선택한 직원의 연도·월별 허용 기록을 보여줍니다. 참석 상태를 구분하고, 미참석 기록을 완료된 성장으로 표시하지 않습니다.
3. **상세 연결:** 허용된 교육·현장 코칭·본인 작성 매니저 코칭의 상세를 다시 조회합니다. 직원 실행 계획과 후속 이력도 기존 권한을 통과한 경우에만 읽기 전용으로 연결합니다.
4. **통합 화면:** 기존 아카데미의 홈·학습·직원 관리 구성을 검수 전용 화면 안에 재사용합니다. 별도 ‘마이그로스’ 진입 메뉴를 새로 추가하지 않습니다. 기존 담당 지정·교육·참석·계획 업무는 운영 업무 위치와 연결해 보여주되, 기존 서비스 화면은 변경하지 않습니다.
5. **직원 화면:** 직원 본인의 홈·월별 기록·학습·코칭 상세도 같은 검수 전용 틀에서 확인할 수 있도록 준비합니다. 본인 조회와 담당자의 타인 조회 권한은 분리합니다.

이번 범위의 담당 직원 여정은 **허용된 기록만 모은 화면**이며 직원의 모든 기록을 공개하는 화면이 아닙니다. 다른 직원의 기존 이러닝 전체 이력은 새 권한을 만들지 않으며, 허용 근거가 없는 항목은 제외합니다.
