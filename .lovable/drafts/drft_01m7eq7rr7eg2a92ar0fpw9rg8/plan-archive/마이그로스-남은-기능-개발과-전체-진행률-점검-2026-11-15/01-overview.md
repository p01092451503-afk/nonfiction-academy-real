# 마이그로스 남은 기능 개발과 전체 진행률 점검

## 이번에 진행할 내용

기존에 연결한 화면을 다시 만들지 않습니다. 같은 원본 기록이 네 화면에서 정확하게 보이는지 먼저 검수하고, 다음 미완료 항목인 교육자료 등록·내려받기를 준비합니다. 모든 작업은 현재 검수 초안에서만 진행하며 초안을 수락하거나 운영 사이트에 게시하지 않습니다.

**착수 확인:** 이번 운영 연결 차단 점검 20항목을 통과했습니다. 외부 요청 5곳이 실제로 차단됐으며 시험 메일은 내부 시험 수신함에만 도착했습니다. 이전 검수 결과를 이번 근거로 재사용하지 않습니다.

## 1. 같은 원본 기록을 값별로 대조합니다

- 분리된 합성 직원·담당자 계정으로 대시보드, 내 강의, 직원 관리, 성장 조회를 확인합니다.
- 온라인 진도·수료·학습시간, 오프라인 참석·계획 및 실제 시간, 코칭 본문, 실행 계획, 최초 판정·정정 이력을 목록·상세·새로고침 후 대조합니다.
- 결과를 **일치 / 불일치 / 권한상 제외 / 검수 불가**로 구분합니다. 담당 직원의 온라인 기록 전체가 기존 권한 밖이라면 새로 공개하지 않습니다.
- 다른 지점, 다른 매니저, 직원·담당자 소속 변경과 지정 해제 이후의 직접 조회·상세 접근을 실제로 검사합니다.
- 결함이 확인되면 해당 범위만 최소 수정하고 같은 검수를 다시 수행합니다.

## 2. 확정한 교육자료 기준을 적용합니다

| 항목 | 적용 기준 |
|---|---|
| 허용 파일 | 워드·PDF·엑셀·PPT입니다. 기존 형식과 최신 형식을 포함합니다. |
| 최대 용량 | 파일 한 개당 50MB입니다. |
| 보관 | 자동 삭제 없이 영구 보관합니다. 저장 한도와 백업 보장까지 뜻하는 것은 아닙니다. |
| 다운로드 링크 | 발급일부터 일주일 동안 유효합니다. |
| 등록 | 기존 교육 담당 범위 안에서만 허용합니다. |
| 직원 조회 | 참석이 확인된 직원 본인에게만 허용합니다. |
| 차단 | 참석 전·미참석·타 지점·지정 해제·소속 변경은 현재 권한 기준으로 차단합니다. |

교육 운영의 교육 상세에 자료 등록·목록을 연결하고, 직원의 학습 상세와 허용된 담당 직원 상세에 같은 자료를 연결합니다. 코칭 자료나 공개 자료는 추가하지 않습니다. 시험 파일만 사용하며 실제 운영 파일을 복사하지 않습니다.
