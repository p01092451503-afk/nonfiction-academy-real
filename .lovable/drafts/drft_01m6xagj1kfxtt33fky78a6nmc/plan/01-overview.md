# 직원·담당자 저장 시연을 다시 확인합니다

현재 초안에서만 시연합니다. 운영 회원이나 실제 학습 자료를 복사하지 않고, 초안도 수락하거나 게시하지 않습니다. 이전 검수 결과는 이번 완료 근거로 사용하지 않습니다.

## 먼저 확인한 안전 조건

운영 연결 차단을 적용한 뒤 20개 점검을 모두 통과했습니다. 외부 연결 5곳은 실제로 차단됐고, 시험 메일은 내부 수신함에만 도착했습니다. 예약작업과 외부 전송 권한도 차단했으며, 서버 함수의 직접 통신 호출은 발견하지 못했습니다. 시연 중 실패나 미확인 사항이 생기면 저장을 중단합니다.

## 이번 시연 범위

- 기존 기능을 다시 개발하지 않고, 최소 합성 계정과 예시 자료로 실제 저장·조회만 검수합니다.
- 직원이 현장 코칭의 실행 계획을 저장하고 새로고침 후 같은 내용을 확인합니다.
- 담당 트레이너가 동일 계획을 조회하고 판정을 저장·정정합니다. 새로고침 후 처음 판정과 정정 이력이 모두 남는지 확인합니다.
- 직원이 다시 로그인해 본인 결과를 읽기 전용으로 조회합니다.
- 매니저 코칭에서도 같은 흐름을 별도로 반복합니다.
- 담당자는 본사 한국 교육팀이 지정한 본인 소속 지점의 선임매니저 범위를 유지합니다.
