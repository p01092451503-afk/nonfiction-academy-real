## 검수 기준과 결과물

- 실제 로그인 상태에서 저장한 자료가 새로고침 후 같은 사용자·담당자 화면에 다시 나타나야 합니다.
- 화면 접근뿐 아니라 직접 자료 조회와 저장도 권한 범위 밖에서는 차단되어야 합니다.
- 실패, 환경 제약, 미검수는 완료와 구분합니다. 필요한 오류만 수정하며 새 기능 전체를 확대 구현하지 않습니다.
- 한국어 화면 캡처와 짧은 회의 안내를 제공합니다. 비밀번호·인증값은 포함하지 않습니다. 첨부 기획서와 시안은 접근 가능한 경우 대조합니다.
- 최종 안내에는 이 초안에서 확인할 주소, 완료·미완성·미검수·고객 결정 대기, 다음 대기 기능을 구분합니다.
- 종료 전에 운영 격리를 다시 검증하고 작업 목록과 변경 내용을 저장합니다.

## 이번에 구현하지 않는 범위

팀 직원별 전체 성장 조회, 팀 현황·보고, 교육자료 내려받기는 미완성으로 남깁니다. 판정 의미를 임의 변경하지 않습니다. 현재 이행 완료·진행 중·미이행과 기획서의 개선됨·추가 개선 필요의 차이를 회의 결정 항목으로 표시합니다.

예정일, 모바일 피드백 탭, 매니저의 현장 코칭 열람 범위, 판정 이후 계획 수정 제한, 보고 계산은 고객 결정 없이 확대하지 않습니다.

## 기술 확인 범위

기존 서버 검수 명단·담당 지정·소속 지점 확인과 저장 함수를 그대로 사용합니다. 브라우저 설정으로 권한을 대신하지 않습니다. 예시 자료는 초안의 재사용 가능한 준비 파일에 기록해 한 번에 적용합니다. 기존 업무 검사와 실제 브라우저 검수를 함께 수행합니다.
