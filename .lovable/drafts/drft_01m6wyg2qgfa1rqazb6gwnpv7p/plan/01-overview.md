# 마이그로스 저장 시연 재검수 계획

## 이번 목표

2026년 11월 18일 회의에서 직원과 담당자의 실제 저장·조회 흐름을 보여줄 수 있도록 현재 초안에서 재검수합니다. 이전 초안의 완료 기록이나 자동 검사만으로 완료 처리하지 않습니다.

## 확인한 안전 조건

현재 초안은 별도 시험 자료 공간을 사용합니다. 2026년 11월 8일 운영 연결 차단 적용과 검증 20개 항목을 모두 통과했습니다. 외부 메일·연동·파일 연결을 차단하고 활성 예약작업과 외부 전송 대기 건수가 없음을 확인했습니다. 이전 계획은 다른 초안의 기록이며, 현재 초안에 승인된 같은 범위 계획은 확인되지 않습니다.

운영 서비스·학습 기록·역할·예약작업·백업·외부 연동은 변경하지 않습니다. 검수 중 차단 검증에 실패하면 즉시 중단합니다. 초안은 수락하거나 게시하지 않고 열어 둡니다.

## 진행 순서

1. 합성 계정과 최소 예시 자료를 확인합니다. 검수 명단, 소속 지점, 본사 한국 교육팀 지정 및 선임매니저 자격을 확인합니다. 운영 자료는 복사하지 않습니다.
2. 직원 로그인부터 성장 홈·월별 기록·코칭 상세·본인 계획 저장·새로고침 재조회까지 확인합니다.
3. 같은 지점에 지정된 담당자가 직원 계획을 조회하고 판정·정정을 저장합니다. 새로고침 후 최초·정정 이력이 유지되는지 확인합니다.
4. 동일 직원으로 다시 로그인해 판정 이력을 읽기 전용으로 확인합니다.
5. 교육 등록·참석 저장·직원 학습 목록 반영과 매니저 코칭 전체 저장 흐름을 각각 재검수합니다.
6. 미허용 계정·다른 지점의 조회와 저장 차단, 기존 네 역할 화면 유지, 컴퓨터·휴대전화 화면을 확인합니다. 관련 기존 검사도 실행합니다.
