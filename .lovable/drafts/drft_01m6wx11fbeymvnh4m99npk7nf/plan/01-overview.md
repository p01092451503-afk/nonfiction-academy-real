# 11월 18일 회의용 실제 저장 시연 준비

## 먼저 확인한 내용

- 「마이그로스 회의용 저장 시연·독립 검수」의 별도 시험 공간을 확인합니다. 운영 연결 차단 적용과 재검증에서 **20개 항목이 모두 통과했습니다**.
- 성장 홈·월별 기록·학습·코칭 상세·실행 계획과 담당자 업무 화면이 이미 있습니다. 기존 저장 기능을 그대로 사용하며 권한을 넓히지 않습니다.
- 이 초안에 예시 검수 명단 4건, 교육·코칭 5건, 실행 계획 1건이 있습니다. 자료가 있다는 사실만 확인했으며, 이번 초안의 실제 저장 시연은 아직 검수하지 않았습니다.

## 최소 준비 범위

1. 합성 직원·본사 한국 교육팀·지점 선임매니저 계정과 예시 자료의 관계를 확인합니다. 부족한 자료만 이 초안에 추가합니다. 본사 지정과 본인 소속 지점 조건을 그대로 따릅니다.
2. 같은 직원·코칭 자료로 아래의 저장 시연을 실제 화면에서 수행합니다. 새로고침 후 다시 나타나는 내용을 근거로 결과를 판단합니다.
3. 교육 등록·참석 저장 후 직원 학습 목록 반영을 확인합니다. 매니저 담당자의 새 화면 전체 저장 흐름도 가능하면 별도로 검수하며, 수행하지 못한 경우 미검수로 명시합니다.
4. 권한 없는 계정과 다른 지점의 조회·저장 차단, 기존 네 역할의 로그인·학습·메뉴 유지, 컴퓨터·휴대전화 화면을 확인합니다.

새 기능 개발이나 화면 재설계는 하지 않습니다. 시연을 막는 문제가 발견되면 요청 범위 안에서 최소한으로 보완하고 동일한 검사를 다시 수행합니다. 격리 검사 실패 시에는 즉시 중단합니다.
