## 진행 순서

1. 합성 계정과 최소 예시 자료를 확인합니다. 검수 명단, 소속 지점, 본사 한국 교육팀 지정 및 선임매니저 자격을 확인합니다. 운영 자료는 복사하지 않습니다.
2. 직원 로그인부터 성장 홈·월별 기록·코칭 상세·본인 계획 저장·새로고침 재조회까지 확인합니다.
3. 같은 지점에 지정된 담당자가 직원 계획을 조회하고 판정·정정을 저장합니다. 새로고침 후 최초·정정 이력이 유지되는지 확인합니다.
4. 동일 직원으로 다시 로그인해 판정 이력을 읽기 전용으로 확인합니다.
5. 교육 등록·참석 저장·직원 학습 목록 반영과 매니저 코칭 전체 저장 흐름을 각각 재검수합니다.
6. 미허용 계정·다른 지점·검수 권한이 폐지된 계정의 조회와 저장 차단, 기존 네 역할 화면 유지, 컴퓨터·휴대전화 화면을 확인합니다. 관련 기존 검사도 실행합니다.

## 검수 기준과 결과물

- 실제 로그인 상태에서 저장한 자료가 새로고침 후 같은 사용자·담당자 화면에 다시 나타나야 합니다.
- 화면 접근뿐 아니라 직접 자료 조회와 저장도 권한 범위 밖에서는 차단되어야 합니다.
- 실패, 환경 제약, 미검수는 완료와 구분합니다. 필요한 오류만 수정하며 새 기능 전체를 확대 구현하지 않습니다.
- 단계별 한국어 화면 캡처와 회의 요약을 파일로 제공합니다. 비밀번호·인증값은 포함하지 않습니다. 첨부 기획서와 고객 시안은 접근 가능한 경우 대조하고, 접근하지 못하면 비교 미검수로 표시합니다.
- 최종 안내에는 이 초안에서 확인할 주소, 완료·미완성·미검수·고객 결정 대기, 다음 대기 기능을 구분합니다.
- 종료 전에 운영 격리를 다시 검증하고 작업 목록과 변경 내용을 저장합니다.

## 이번에 구현하지 않는 범위

교육자료 업로드·다운로드, 담당 직원 성장 조회·팀 현황, 시간 보고·집계, 외부 성과 연동, 과거 자료 이관, 기록 번역은 현재 소스와 검증 결과를 근거로 완료·부분·미구현·미검수로 구분합니다. 이번 재검수에서 새 기능을 확대 구현하지 않습니다. 현재 판정인 이행 완료·진행 중·미이행과 기획서의 개선됨·추가 개선 필요의 의미 차이, 예정일 관리 부족을 회의 결정 항목으로 표시하며 임의 변경하지 않습니다.

예정일, 모바일 피드백 탭, 매니저의 현장 코칭 열람 범위, 판정 이후 계획 수정 제한, 보고 계산은 고객 결정 없이 확대하지 않습니다.

## 기술 확인 범위

기존 서버 검수 명단·담당 지정·소속 지점 확인과 저장 함수를 그대로 사용합니다. 브라우저 설정으로 권한을 대신하지 않습니다. 예시 자료는 초안의 재사용 가능한 준비 파일에 기록해 한 번에 적용합니다. 기존 업무 검사와 실제 브라우저 검수를 함께 수행합니다.

## 승인 범위

이 계획 승인은 이 초안에서 검수와 필요한 최소 오류 수정을 시작한다는 뜻입니다. 초안을 수락하거나 운영 사이트에 게시한다는 뜻이 아닙니다. 실제 저장 시연은 계획 승인 후 진행합니다.
