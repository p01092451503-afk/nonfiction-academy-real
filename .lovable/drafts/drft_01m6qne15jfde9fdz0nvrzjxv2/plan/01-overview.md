# 0단계 격리 검증 작업 계획

운영에 연결하지 않고 현재 초안에서만 확인합니다. 운영 자료·권한·예약작업과 게시 설정은 변경하지 않습니다.

1. 실제 초안 연결 주소, 파일·인증 응답, 서버·예약작업의 설정과 조회 결과를 기록합니다.
2. 검수 브라우저에서는 승인한 초안 연결만 허용합니다. 서버 기능 호출, 자료 변경, 외부 이동과 전송은 차단합니다. 서버·예약작업의 차단을 증명하지 못하면 전체 판정은 실패로 유지합니다.
3. 별도 마이그로스 주소에 접근 차단 틀을 추가합니다. 공개는 기본 중지하고 허용 명단은 비워 둡니다. 기존 관리자 역할에 예외를 주지 않습니다. 직접 접근하면 기존 시작 화면으로 조용히 이동합니다.
4. 예제 계정으로 안전하게 확인할 수 있는 기존 화면을 변경 전후 비교합니다. 없는 역할이나 안전 조건 때문에 확인하지 못한 화면은 실패로 기록합니다.
5. 항목별 결과·근거·남은 위험·1단계 착수 여부를 지정한 한국어 보고서에 저장합니다.

## 기술 적용 범위

기존 메뉴·권한·자료 구조는 그대로 유지합니다. 별도 접근 판정 함수와 차단 경로, 초안 검수용 통신 통제 도구 및 작은 규칙 검사를 추가합니다. 서버 권한 기반 허용과 업무 조회는 전체 격리 통과 전에는 활성화하지 않습니다. 검수 도구의 차단을 일반 초안 전체의 서버 차단으로 표현하지 않습니다.
