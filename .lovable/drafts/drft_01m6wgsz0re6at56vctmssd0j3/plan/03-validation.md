## 검수
1. 실제 예시 계정으로 판정 저장 → 새로고침 → 재조회 → 정정 → 이전 이력 보존을 확인합니다.
2. 직원 본인·다른 지점·다른 종류 담당자·해제된 담당자·검수 명단 밖 계정의 무단 저장과 조회를 차단합니다.
3. 이력 직접 수정·삭제 금지와 동시 저장 충돌, 같은 요청 재전송의 중복 방지를 자동 검사합니다.
4. 기존 학습자·관리자·최고관리자·러닝매니저의 로그인·학습·메뉴 회귀 검사를 실행합니다.
5. 컴퓨터와 휴대전화에서 화면을 확인하고 결과와 확인 주소를 안내합니다.

## 기술 구현
- 새 판정 이력 표는 클라이언트 직접 권한 없이 서버 함수로만 접근합니다. 수정·삭제를 거부하는 보호 장치를 추가합니다.
- 현재 `mygrowth_session_scope`를 그대로 사용하고 지정 역할·현재 직원 소속을 추가 검증합니다.
- 계획 잠금, 판정 버전, 계획 수정 시점, 요청 식별자로 저장의 일관성을 보장합니다.
- `scripts/test-mygrowth-10-followup.py`를 추가하고 기존 실행 계획 검사와 `scripts/check-mygrowth-regression.py`를 실행합니다.
- 이 초안의 예시 자료로만 검수하며 기존 이러닝 화면과 기록은 수정하지 않습니다.
