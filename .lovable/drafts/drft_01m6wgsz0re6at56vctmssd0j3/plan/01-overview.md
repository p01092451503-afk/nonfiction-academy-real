# 10번 후속 확인

운영 차단 점검을 모두 통과했습니다. 이 초안에서만 개발하며 **수락하거나 게시하지 않습니다.**

## 만들 기능
- `/my-growth/plans`의 **담당 직원 계획**에서 이행 완료·진행 중·미이행을 선택하고 판정 의견을 저장합니다.
- 판정을 반복하거나 정정해도 이전 기록은 남습니다. 판정 당시 실행 계획 내용, 담당자, 시간, 상태, 의견을 함께 보존합니다.
- **내 계획**에서는 본인 판정과 전체 이력을 읽기 전용으로 확인합니다.
- 다른 담당자가 먼저 저장했거나 직원이 계획을 수정하면 최신 내용을 다시 확인한 뒤 저장하도록 합니다.

## 접근 기준
현재 검수 명단과 담당 범위를 모두 확인합니다. 판정 저장은 소속 지점의 지정 트레이너·스토어매니저만 허용하며, 기존 교육·필드·매니저 코칭의 담당 범위를 넓히지 않습니다. 직원 본인은 판정할 수 없습니다.
