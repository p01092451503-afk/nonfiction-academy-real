## 완료 기준과 제공 자료

- 실제 로그인 상태에서 저장한 내용이 새로고침 후 같은 직원·담당자의 화면에 다시 나타나야 합니다.
- 권한 범위 밖에서는 화면 진입뿐 아니라 직접 조회·저장도 차단되어야 합니다.
- 단계별 화면 캡처, 쉬운 한국어 시연 안내, 실제 확인 결과와 미완성 항목을 사용자용 파일로 제공합니다. 비밀번호·토큰은 자료와 로그에 남기지 않습니다.
- 교육자료·팀 보고·외부 연결·번역은 현재 구현 근거에 따라 구분하며 작동하는 것처럼 표시하지 않습니다. 외부 영상은 운영 연결 차단으로 확인하지 못하면 미검수로 표시합니다.
- 기획서와 다른 판정 표현·예정일, 팀 열람 범위, 판정 이후 계획 수정 제한은 결정 대기로 명시하고 임의 변경하지 않습니다.

## 기술 확인 범위

기존 검수 명단·담당 지정·소속 지점 확인과 저장 함수를 그대로 사용합니다. 예시 자료가 필요하면 재사용 가능한 준비 파일에 기록한 뒤 이 초안에만 적용합니다. 기존 검수 스크립트는 재사용하되 현재 환경에서 새로 실행한 결과만 보고합니다. 필요한 오류가 실제 재현될 때만 최소 수정합니다.

## 승인 범위

이 계획 승인은 현재 초안에서 검수를 시작한다는 뜻이며 초안 수락이나 운영 게시가 아닙니다. 실제 저장 시연은 사용자가 이 계획을 직접 승인한 뒤 진행합니다.
