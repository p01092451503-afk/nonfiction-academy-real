# 직원·담당자 실제 시연 검수 계획

「마이그로스 11월 18일 회의·직원 담당자 시연」 초안에서 직원의 실행 계획 저장부터 담당자의 후속 판정까지 실제 화면으로 다시 확인합니다. 이전 초안의 성공 기록을 이번 결과로 사용하지 않습니다.

## 확인한 운영 보호 조건

2026년 11월 8일 10:00 협정세계시 기준 운영 분리 점검 20개를 모두 통과했습니다. 외부 메일·연결·파일 전송을 차단하고 활성 예약작업과 외부 전송 대기 건수가 없음을 확인했습니다. 서버 함수의 직접 통신 호출도 발견되지 않았습니다. 실제 시연 전 차단이 유지되는지 다시 확인하며, 실패하거나 운영 의존성이 남으면 즉시 중단합니다.

운영 사이트, 실제 회원·학습·백업 자료를 변경하지 않습니다. 이 초안은 수락하거나 게시하지 않습니다.

## 시연 순서

1. 최소 합성 계정과 예시 자료를 확인합니다. 담당자는 본사 한국 교육팀이 지정한 본인 소속 지점의 선임매니저만 사용합니다. 관리자 역할만으로 권한을 넓히지 않습니다.
2. 직원이 성장 홈에서 현장 코칭 상세를 열고 본인 실행 계획을 저장합니다. 새로고침 후 같은 내용이 다시 나타나는지 확인합니다.
3. 해당 지점 담당자가 같은 직원의 계획을 조회하고 후속 판정과 정정을 저장합니다. 새로고침 후 최초 판정과 정정 이력을 확인합니다.
4. 직원으로 다시 로그인해 결과를 읽기 전용으로 확인합니다.
5. 매니저 코칭의 등록·참석·계획·판정 저장 흐름도 별도로 확인합니다.
6. 권한 없는 사용자와 다른 지점의 조회·저장 차단, 기존 네 역할 화면 유지, 컴퓨터와 휴대전화 화면을 확인합니다.
